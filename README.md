# Business Hub prototype

Clickable prototype of the Smartpress Business Hub redesign, used for usability testing.

**Live preview:** https://sp-narniax.github.io/business-hub/

Built from the Figma Make file "Business Hub (future state v3)". `index.html` is a single self-contained file (all code, styles and images inlined), so it runs on GitHub Pages with no build step.

## Screens you can link to directly

- Dashboard: `/business-hub/`
- Request a product: `/business-hub/#create-new-product`
- Request details: `/business-hub/#request-details`
- Personalize a saved product: `/business-hub/#personalize?product=Demo%20Product`
- Cart: `/business-hub/#cart`

## Updating

Replace `index.html` with a new build and commit. GitHub Pages republishes automatically within a minute or two.
